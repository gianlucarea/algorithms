# Algorithms, one problem at a time

A growing collection of my Python solutions to **[Grind 169](https://www.techinterviewhandbook.org/grind75/?hours=5&weeks=20)**, the expanded version of Grind 75. I usually solve one problem a day, using the practice to sharpen my algorithmic thinking and write clear, efficient code.

The problems span arrays, strings, linked lists, trees, graphs, binary search, and dynamic programming. Each solution lives in its own file, named with the problem number and title so it's easy to browse.
